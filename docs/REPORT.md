## Built but untested (needs your iPad / machine)

- **Everything the iPad app does at runtime:**
  - coalesced 240 Hz capture
  - hover via `UIHoverGestureRecognizer`
  - `UIPencilInteraction` double-tap/squeeze
  - `UICanvasFeedbackGenerator` haptics
  - the Network.framework TLS listener with client-certificate verification
  - keychain identity creation with swift-certificates
  - the pairing UI
  - Bonjour advertising

  It compiles against the iOS 26.5 SDK; none of it has run. The most likely trouble spots:
  1. the TLS verify block / identity handling, which compiled but may need tweaks;
  2. whether usbmux connections reach a listener bound to `127.0.0.1` (**assumption**, per PeerTalk/Appium);
  3. hover and touch ordering around stroke starts.
- **KDE integration:**
  - `[kde] output` pin-to-screen through KWin D-Bus `outputName` (via `busctl`);
  - the device appearing in System Settings → Drawing Tablet;
  - Krita picking up pressure, tilt and rotation with no extra configuration.

  libinput behaves as designed in CI, but KWin and Krita were never run. **Assumption** (high confidence for the libinput part).
- `scripts/doctor.sh`, `setup-system.sh`, `install-daemon.sh`, `resign-ipad.sh`: shellchecked, and doctor.sh dry-ran in the VM. Never run on Arch.
- **The real USB latency:** not measured. That's [MORNING.md §8](MORNING.md).

## Things you should know

- **Port changed to 47811/47812** because InkLink (a two-day-old MIT project with the same idea) uses 47800. InkLink has no encryption, hover or haptics. We share no code; collaborating is your call.
- **Free Apple ID:** the app needs no restricted entitlement. xtool and SideStore must not share an Apple ID: they revoke each other's certificate.
- **The default gesture mapping** is double-tap = eraser toggle and squeeze = BTN_STYLUS2 click (right button → Krita pop-up palette). Change it in `[pencil]`.
- **Possible security issues in Tether**, found while reading its code (shared fingerprint variable, share extension not verifying the pin): see [tether.md](tether.md). Not reported upstream; your call.
- **A small leak during the overnight research:** one of the research steps sent your email address in the User-Agent header of a single crates.io version lookup (an HTTP request to crates.io's public API). Nothing else left the VM.
- **What the VM ran:** git, gh, Rust, evtest, libinput-tools, shellcheck, librsvg (for the icon). No xtool, iOS SDK or Xcode was installed, and no Apple credentials exist anywhere in this repo or in CI.
